# Product Overview

This is a **Video Games Dashboard** built with Streamlit for exploratory data analysis of the CORGIS video games dataset.

## Purpose

Interactive web application that allows users to:
- Upload and explore video game sales and metrics data
- Visualize distributions of game attributes (sales, scores, playtime)
- Compare performance across genres and platforms
- Analyze correlations between variables (sales, review scores, etc.)

## Target Users

Data analysts, researchers, or enthusiasts interested in video game industry trends and patterns.

## Language

The UI is in **Spanish** (español) - all labels, descriptions, and documentation should maintain Spanish language conventions.
